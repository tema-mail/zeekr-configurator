## Как понять, что модель подходит (проверить до покупки)

- [ ] **Лицензия** разрешает использование на коммерческом сайте (Royalty Free или Commercial). Одной редакционной лицензии (Editorial) мало.
- [ ] **Есть салон.** Без него не будет работать «Салон 360°», а смена цвета салона ни на что не повлияет. На превью должны быть фото интерьера.
- [ ] **Формат:** `.glb` / `.gltf` подходит сразу. `.blend`, `.fbx` или `.obj` тоже годятся, но их придётся перевести в `.glb` в Blender (это бесплатно).
- [ ] **Кузов окрашен отдельным материалом**, не одной текстурой вместе со всем остальным. Иначе перекрашивать будет нечего. Обычно это видно по скриншотам материалов или описанию «separate materials».
- [ ] **Диски отдельными объектами или материалом** от шин.
- [ ] **Полигонов** разумное количество: до 1 млн треугольников нормально. Если больше, на телефонах будет тормозить, и модель нужно будет упрощать (Decimate в Blender).
- [ ] Желательно, чтобы колёса были **отдельными объектами**: тогда потом можно сделать подмену дисков разной формы, а не только цвета.

## Как подготовить модель в Blender

1. Открыть файл. Если пришёл `.fbx` или `.obj`, загрузить его через File → Import.
2. **Масштаб:** 1 единица = 1 метр, длина машины как у настоящей (около 5 м). Посмотреть размеры можно в N-панели → Item → Dimensions.
3. **Положение:** машина стоит колёсами на полу (нижняя точка шин на высоте 0), по центру сцены.
   **Перед машины** смотрит в сторону +Y в Blender (после экспорта это −Z в конфигураторе), как у заглушки. Тогда ракурсы из настроек подойдут почти без правок. Если перед смотрит в другую сторону, ничего страшного: просто подобрать ракурсы заново (п. 3 раздела «Как подключить»).
4. **Названия материалов:** дать понятные имена, например `Paint` (кузов), `Rim` (диски), `Leather` (кожа салона). Их потом пропишем в настройках.
5. Применить модификаторы и удалить лишнее: камеры, свет, фон, землю.
6. Экспорт: File → Export → glTF 2.0. Формат **glTF Binary (.glb)**. В разделе Data → Compression включить **Draco** (файл станет в 5–10 раз легче). Хороший итоговый размер — до 20–30 МБ.

## Как подключить

1. Положить `.glb` в `assets/models/`, например `assets/models/zeekr-8x.glb`.
2. В `data/zeekr-8x.json`, раздел `model`:
   - `url` — путь к файлу: `"assets/models/zeekr-8x.glb"`;
   - `targets` — что перекрашивается. Для каждой группы можно указать имена материалов (`materials`) или объектов (`nodes`):
     ```json
     "targets": {
       "paint":    { "materials": ["Paint"] },
       "rims":     { "materials": ["Rim"] },
       "interior": { "materials": ["Leather"] }
     }
     ```
     Узнать имена в готовом `.glb` можно, перетащив файл на https://gltf-viewer.donmccurdy.com — там видно дерево объектов и материалов.
     Если какое-то имя не найдено, в консоли браузера (F12) будет предупреждение `группа «…» не найдена в модели`.
3. `views` — ракурсы камеры. Координаты в метрах: `camera` — где стоит камера, `target` — куда смотрит.
   - `exterior` — общий вид снаружи;
   - `interior` — место водителя: `camera` примерно на уровне глаз над водительским сиденьем, `target` — вперёд, сквозь лобовое стекло;
   - `dashboard` — вид на центральный экран.
   Подбирать удобнее всего так: поменять цифры, сохранить, обновить страницу.
4. Удалить строку `"demoNotice"` — пропадёт пометка «Демо-модель».
5. Удалить `assets/models/placeholder.glb` и строчку про Ferrari в README.

## Если модель тяжёлая или тормозит

- Проверить, что при экспорте включён Draco.
- Сжать текстуры: в Blender уменьшить картинки до 2048 px, либо прогнать готовый `.glb` через https://gltf.report (вкладка Script, функции `textureCompress` / `resize`).
- Упростить невидимые детали: подвеску, двигатель, днище.
