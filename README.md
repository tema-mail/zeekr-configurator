# Конфигуратор автомобиля

Статический сайт: HTML + CSS + JS, 3D на Three.js. Сборка не нужна.

## Как выложить

Залить папку целиком на любой хостинг статики (nginx, Caddy, Netlify, S3 и т.п.).
Открывать именно через веб-сервер: если просто открыть `index.html` двойным кликом, браузер не даст загрузить модель и данные.

Проверить локально:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Что где лежит

| Файл | Что внутри |
|---|---|
| `data/zeekr-8x.json` | Все комплектации, цвета, диски, опции, услуги, цены, НДС, условия кредита. Правится без программиста. |
| `assets/models/zeekr-8x.glb` | 3D-модель Zeekr 8X Ultra 2026 (куплена 03.11.2026, Zifir3d / Superhive), сконвертирована из Scene.blend. |
| `assets/panos/single`, `assets/panos/dual` | Панорамы салона 360° (по 6 граней 1280 px) для одного и двойного экрана, с конфигуратора Auto China. |
| `js/stage.js`, `assets/stage/` | Стенд-шоурум: купол, отражающий пол, подиум со светящимся кольцом, светящийся логотип Evolution Car (настройки – `model.stage` в JSON). |
| `js/viewer.js` | 3D-сцена: свет, камера, перекраска частей модели, панорама салона. |
| `js/app.js` | Шаги, выбор, пересчёт цены, форма заявки. |
| `css/style.css` | Оформление. Цвета — в начале файла (`:root`). |

## 3D-модель

Стоит купленная Zeekr 8X Ultra 2026. Как она подготовлена и как пересобрать, описано в **[MODEL.md](MODEL.md)**.

## Фото опций и ракурсы камеры

- 3D-модель меняется только на шагах «Цвет кузова», «Диски» и «Салон». Остальные шаги меняют цену.
- Чтобы в карточке опции было фото, добавить опции поле `"image": "assets/options/имя.webp"` и положить картинку в эту папку.
- У каждого шага есть поле `"view"`: какой ракурс показать (`exterior`, `interior`, `dashboard`). Сами ракурсы задаются в `model.views`. Если поставить `"inside": true`, камера окажется в салоне.

## Другая машина

Скопировать `data/zeekr-8x.json` под новым именем, например `data/zeekr-9x.json`, и открыть `index.html?car=zeekr-9x`.
